# mist-ytp

Script-driven YouTube Poop renderer. You write the edit as a YAML timeline of
one-line items (clips, word-level sentence mixes, freeze frames, title cards),
each with a chain of effects, and `mist-ytp` renders it through ffmpeg.
faster-whisper finds the words for sentence mixing.

Built for a Pantheon YTP (Sept 2026). Nothing in the tool is show-specific.

## Setup

```bash
uv venv --python 3.12 mist-ytp/.venv
uv pip install --python mist-ytp/.venv/bin/python pyyaml faster-whisper pillow
mist-ytp/bin/mist-ytp fetch-assets      # Kevin MacLeod tracks + uisfx cues -> assets/
```

Needs `ffmpeg` on PATH. The first alignment downloads whisper `small.en`
(~480 MB). Set `MIST_YTP_WHISPER=medium.en` for a bigger model.

## Workflow

```bash
mist-ytp index   show.yaml                 # extract subtitle tracks -> work/lines.tsv
mist-ytp grep    show.yaml 'meat ?loaf'    # find lines with timestamps
mist-ytp inspect show.yaml S01E01@34:35    # cues, whisper words, voiced spans
mist-ytp peek    show.yaml S01E01@34:34 S02E03@17:07 -o faces.png   # stills, to pick freeze frames
mist-ytp render  show.yaml --dry           # resolve every phrase, print the cuts
mist-ytp render  show.yaml -o out.mp4      # render (unchanged items come from cache)
mist-ytp hear    out.mp4 --timeline work/timeline.tsv   # transcribe item by item
mist-ytp sheet   out.mp4 -o sheet.png --every 1.25      # contact sheet
```

`hear` is the review loop: it transcribes each rendered item on its own, so a
bad cut shows up as a wrong line in the list. Whisper run over a whole YTP
loses the thread after the first heavily processed item.

## Project file

```yaml
size: [1280, 720]
fps: 24000/1001                  # must divide 48 kHz into whole samples
sources:
  glob: "~/Media/Show/Season */*.mkv"
  key: 'S\d\dE\d\d'              # regex on the filename -> source key
  subs: {default: 2, "S01E*": 3} # subtitle stream index per key glob
level: -20                       # speech level every source slice is gained to (null = off)
assets:
  bed: "km:Monkeys Spinning Monkeys"
  boom: "synth:boom"
  hi: "say:S01E01@40:07 hi kiddo" # an aligned line, for dubbing onto another picture
credits:
  lines: ["a YouTube Poop by ..."]
timeline:
  - S01E01@03:59 "i don't want this stupid computer" | stutter 0.14 3
  - S01E01 34:36.10-34:37.70
  - mix S01E01@40:39 "we are" / S01E01@18:32 "out of milk"
  - freeze S01E08 17:02.4 1.5 | zoomin 1.6; sfx hi 0.15 2
  - card 2.2 "UPLOADING...\n12%" | font arialblack; size 60; bg 0x10233f; music bed -9
  - credits 8
```

YAML gotchas: inside an unquoted item, ` #` starts a comment and `: ` makes a
mapping. Write colours as `0xRRGGBB` and avoid `: ` in card text.

## Items

| Item | Meaning |
|---|---|
| `KEY START-END` / `KEY START+DUR` | a slice of a source |
| `KEY@TIME "phrase"` | the phrase spoken nearest TIME, cut at word boundaries |
| `mix PART / PART / ...` | sentence mix; each part may carry `[fx; fx]` |
| `freeze KEY TIME DUR` | still frame |
| `card DUR "text"` / `black DUR` | title card (Pillow text: `font`, `size`, `fg`, `bg` colour or image) |
| `file PATH [START-END]` | any audio or video file; audio-only gets `bg` behind it |
| `credits DUR` | card listing the project's lines plus every credited sound actually used |

Phrase lookup: whisper word timestamps, then edges snapped to the pauses on the
dialogue channel (a pause is 80 ms or more at least 36 dB below the phrase
peak; stop consonants inside words are shorter). When whisper misses the line or stretches
a word over silence, the phrase is placed inside its subtitle cue and snapped
the same way. `raw` skips the snapping; `pad A B` widens (negative narrows).

## Effects

Chain after `|`, separated by `;`. They apply in order.

- Structure: `stutter LEN N`, `stutterend LEN N`, `loop N`, `pingpong N`,
  `reverse`, `speed X` (tape, pitch follows), `tempo X` (pitch kept),
  `hold SECS`, `prehold SECS`, `cut SECS`, `trim A B`
- Picture: `invert`, `mirror`, `mirrorr`, `mirrorv`, `hflip`, `vflip`, `upside`,
  `rotate DEG`, `spin RPS`, `zoom F [X Y]`, `zoomin F`, `zoomout F`, `shake PX`,
  `deepfry`, `rainbow`, `hue DEG`, `chroma PX`, `pixelate N`, `edge`, `trails`,
  `bw`, `sepia`, `red`, `flash`, `bulge K`, `blur R`, `glitch`, `scramble PX`,
  `text "..." [top|center|bottom] [size]`, `fadein S`, `fadeout S`
- Sound: `pitch SEMITONES`, `vol DB`, `loud [DB]`, `echo`, `robot`, `vibrato`,
  `muffle`, `phone`, `mute`, `bass DB`, `crush BITS`, `chorus`
- Slice options: `pad A B`, `dry` (centre channel only: dialogue without the
  score on 5.1 sources), `raw`, `nolevel`
- Mixing: `sfx NAME [AT] [DB]` (AT < 0 counts from the item's end; rings past
  the cut), `music NAME [DB] [OFFSET]` (consecutive items naming the same track
  share one continuous bed)

## Sounds

- `synth:boom|beep|static|riser|drop|airhorn|click`: generated by ffmpeg
- `km:TITLE`: Kevin MacLeod (incompetech.com), CC BY 4.0. `credits` puts the
  attribution on screen and the render writes `<out>.CREDITS.txt`.
- `ui:PACK/CUE`: [uisfx](https://github.com/romainsimon/uisfx), CC0. 12 packs
  of 78 cues each, in `assets/sfx/uisfx/`.
- `src:KEY START-END`, `say:KEY@TIME phrase`: audio from the sources themselves

## Mixing

Every source slice is gained to `level`, measured as the 90th percentile of
50 ms frames: a one-second cut can be half silence, which drags a mean down.
A sentence mix arrives at one level, and `loud` stays relative to the dialogue. The final pass
applies one static gain to -16 LUFS, then a limiter at -3 dBFS. loudnorm's
dynamic mode ducked everything after a loud item, and hard-clipped audio
overshot 0 dBFS by about 3 dB once AAC-encoded.

## Notes

- Homebrew's ffmpeg has no `drawtext` (no freetype), so text is a
  Pillow-rendered PNG overlaid through `movie=`.
- Every item renders to exactly N frames and N x samples-per-frame PCM samples,
  so items concatenate by stream copy with no drift.
- The cache keys on effect names and args, not their filter code. Bump
  `VERSION` in `mist_ytp.py` after changing how an effect works.
- Media stays out of git (`work/`, `assets/`, `.venv/` are ignored). Keep
  project files for copyrighted sources outside the repo too.
