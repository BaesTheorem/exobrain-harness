# Missing-person search assist

## Where things are

| What | Where |
|---|---|
| The tool | `~/Documents/missing-person/bin/mp` (public repo, **no personal data**) |
| Case files | `~/Exobrain/Areas/Community/Missing Persons/cases/*.toml` |

**The split is the point.** A case file names a living person and describes
them, so case files live in the vault and never in a repo. The repo ships only
`cases/example.toml`, and a test enforces that. Lookup order is
`$MP_CASES_DIR`, then the vault, then the repo.

## Commands

    cd ~/Documents/missing-person
    bin/mp cases                  every case found
    bin/mp status <case>          NCIC + NamUs, and the conflicts between sources
    bin/mp unidentified <case>    rank unidentified-person candidates
    bin/mp news <case>            newsroom sweep
    bin/mp area <case>            terrain around each last-seen claim (slow; Overpass)
    bin/mp scan <case>            everything, rewrites the vault note
    bin/mp watch <case>           scan, notify only on a change

`--national` widens the unidentified sweep past the case's state list.
`--min` sets the score floor. `--all-locations` runs `area` against every
competing last-seen claim, not just the primary.

## Reading the output honestly

This is the part that matters more than the commands.

**Never report a case resolved from one source.** `caseIsResolved` in NamUs
and absence from a state NCIC feed both flip for administrative reasons.
Require both, and still say to confirm with the agency.

**Unidentified-person output is a list of LEADS.** Never call one a match, an
identification, or a likely match, in chat or in a note. Identification is
DNA, dental, prints, or a medical examiner. Route anything worth pursuing to
the investigating agency, never to a county ME as a member of the public.

**Check what each source can actually see before quoting silence.**

- A **state NCIC missing feed** (Missouri: MSHP) is live and daily. A name
  dropping off it is the first public signal an agency cleared the entry.
- A **state unidentified feed** is usually not live. Missouri's holds 42
  records with nothing recovered after Feb 2023, against 115 in NamUs. An
  empty result there is not evidence.
- **NamUs** is current for unidentified sweeps: entry lag across the seven
  states measured is a 16-day median, 93% inside 90 days (2026 recoveries,
  measured 2026-09-16). A clean sweep there does carry evidence. Re-measure
  before leaning on this again.
- **RSS** carries recent items only. A quiet news sweep says nothing about
  what was published six months ago.

**Never trust a WebSearch synthesis on a case.** It invented an age and a
county on this one. Open NamUs, the state feed, or the agency's own post.

## When Alex shows a flyer or asks for an update

1. `bin/mp status <case>` if the case exists; otherwise build the case file
   first (copy `cases/example.toml` into the vault cases dir).
2. Pull the NamUs record directly for the agency-fed version of the facts. It
   frequently contradicts the flyer, and the agency record is the one search
   effort should follow. Record BOTH claims in the case file with provenance
   rather than picking one; `mp status` prints the distance between them.
3. `bin/mp scan <case>` to refresh the vault note.
4. Report what changed, not the whole file.

## Building a new case file

Copy `~/Documents/missing-person/cases/example.toml` into the vault cases
directory and fill it in. Three fields do non-obvious work:

- `height_in` / `weight_lb` are **ranges**. Sources disagree; a point value
  discards the candidate the other source would have caught.
- `recovery_floor` is the **earliest** date any source claims, not the
  best-supported one. It excludes candidates, so an over-tight bound throws
  away real leads.
- `locality_terms` are the place names that keep a common personal name
  attached to this case. Without them the news sweep returns every athlete
  and obituary who shares the name.

Multiple `[[locations]]` blocks are expected, not a problem to clean up.

## Watcher

`watchers/com.exobrain.missing-person-watch.plist` runs `mp watch` daily and
notifies only on a change: NCIC status flip, NamUs edit, new candidate, new
article. Fill in the case id and copy to `~/Library/LaunchAgents/`.

## Tone

A case is about someone's family. State findings plainly, do not dress up a
weak candidate to sound like progress, and do not speculate about what
happened to the person. If a sweep turns up nothing, say so.
