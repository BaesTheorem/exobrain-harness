# Script, language, and written clues

Usually the fastest country-level answer when any text is visible. Use `geo enhance` to
blow up a half-legible sign before guessing at it.

---

## Script identification

| What you see | Script | Where |
|---|---|---|
| Continuous horizontal bar joining letters, rounded shapes in square boxes | **Devanagari** | India (Hindi, Marathi), Nepal, Fiji |
| Same top bar, but blockier letterforms | **Bengali / Assamese** | Bangladesh, West Bengal, Assam |
| Angular, straight-lined, **with** a top bar | **Tamil** | Tamil Nadu, Sri Lanka |
| Very round and looping, **no** top bar (built for palm leaf, avoids straight lines) | **Malayalam** | Kerala |
| Round with many extra loops and swirls | **Telugu** | Andhra Pradesh, Telangana |
| Round, near-identical to Telugu | **Kannada** | Karnataka. Telugu/Kannada is the hardest pair to eyeball |
| Very curvy, like a string of Cs and Os | **Sinhala** | Sri Lanka |
| Right-pointing hooks on top of characters | **Khmer** | Cambodia |
| Many small round loops, some larger flat loops on top | **Lao** | Laos |
| Like Lao but straighter, most letters end in one tight loop | **Thai** | Thailand |
| Near-circular main bodies, denser than Lao, tone marks above and below | **Burmese** | Myanmar |
| Square syllable **blocks** built from circles and straight lines | **Hangul** | South Korea |
| Dense kanji **mixed with** looping hiragana and angular katakana | **Japanese** | Japan |
| Dense characters only, no kana | **Chinese** | Simplified = mainland China; traditional (more strokes, boxier radicals) = Taiwan, Hong Kong, Macau |
| Geometric, uniform monotone strokes | **Greek** | Greece, Cyprus |
| Boxy with small serif hooks on vertical strokes, fused vowel marks | **Ge'ez / Ethiopic** | Ethiopia (Amharic), Eritrea (Tigrinya) |
| No written vowels, squared letterforms, small "crown" serifs | **Hebrew** | Israel |
| Cursive and connected, dots above and below distinguish letters | **Arabic** | MENA; see the Persian/Urdu split below |
| Rounded and flowing, no case, letters vary in height across four lines | **Georgian (Mkhedruli)** | Georgia only |
| Geometric rather than loopy, small hooks and cross-strokes | **Armenian** | Armenia only |
| Boxy vertical strokes, written vertically in traditional form | **Mongolian traditional** | Inner Mongolia signage; Mongolia itself uses Cyrillic |
| Tall stacked characters with small circles and loops | **Tibetan** | Tibet, Bhutan (Dzongkha) |
| Triangular geometric syllabics, reused Latin/Greek-looking symbols | **Cherokee** | Cherokee Nation, USA (rare) |
| Triangular geometric syllabics, dots for vowel length, alongside Roman | **Inuktitut** | Nunavut, Canada |

*Sinhala-vs-Tamil "round vs angular" is community consensus rather than an academic
source. Medium confidence.*

## Latin diacritics as a country fingerprint

The highest-value table here. Verified per-language against Wikipedia orthography pages.

| Language | Distinctive letters |
|---|---|
| **Romanian** | ă â î ș ț. The comma-below ș/ț are correct modern forms; cedilla ş/ţ are a font-substitution artifact, not a different language |
| **Polish** | ą ć ę ł ń ó ś ź ż — exactly 9 special letters |
| **Czech** | č ř š ž ě ň ť ď plus á é í ó ú ý plus ů. **ř is unique to Czech** and is the single best Czech/Slovak/Polish shibboleth |
| **Slovak** | Shares the háček set but has **no ř**, and has ô, which Czech lacks |
| **Hungarian** | **ő ű** (double acute, unique to Hungarian), plus á é í ó ö ú ü |
| **Swedish** | å ä ö |
| **Finnish** | å ä ö (å is rare, only in Swedish loanwords and names) |
| **Danish / Norwegian** | **æ ø å**. The å/ä/ö vs æ/ø/å split is the fastest Swedish vs Danish/Norwegian tell |
| **Turkish** | ğ, **ı** (dotless lowercase i; capital İ has a dot), ş, plus ö ü |
| **Spanish** | ñ |
| **Portuguese** | **ã õ** (nasal tildes, not used in Spanish), plus ç. The #1 Spanish/Portuguese shibboleth |
| **Serbo-Croatian (Latin)** | đ ć č š ž |
| **Latvian** | ā ē ī ū (macrons), plus č š ž |
| **Lithuanian** | ą ę į ų (ogonek), ū, č š ž. Not the same set as Latvian despite both being Baltic |
| **Icelandic** | **þ** (thorn, unique among living Latin-script languages) and **ð** (eth, also Faroese), plus á é í ó ú ý æ ö |
| **Vietnamese** | Tone marks **stacked on top of** base vowel diacritics (ă â ê ô ơ ư). Double-stacked diacritics are unmistakable and unique |
| **French** | é è à ç; the word "rue"; "-ux" plural endings |
| **German** | ä ö ü and **ß** |
| **Dutch** | Almost no diacritics. Identify by the clusters "ij", "oe", "ieuw" |
| **Albanian** | ë; the word "rruga" (street) |

**Romanian vs Italian** — Romanian's five modified letters settle it. Italian has no
dedicated new letters, only accents on plain vowels (à è ì ò ù).

## Cyrillic

| Language | What it adds or is missing |
|---|---|
| **Ukrainian** | ADDS **і ї є ґ**. MISSING ы ъ э ё (uses an apostrophe for ъ) |
| **Bulgarian** | MISSING ы э ё, and no Ukrainian і. **ъ is a real spoken vowel** appearing mid-word constantly, which no other Slavic Cyrillic language does. 30 letters |
| **Serbian** | ADDS 5 letters absent from Russian: **љ њ ђ ћ џ**. Any of those five means Serbian or Macedonian, never Russian/Ukrainian/Bulgarian |
| **Kazakh** | ADDS 9: **ә ғ қ ң ө ұ ү һ і** (42 total) |
| **Mongolian** | ADDS exactly 2: **ө ү**. Russian alphabet plus those two and nothing else |
| **Kyrgyz** | 36 letters with Kyrgyz-specific extras. *Exact list unverified.* |
| **Russian** | Plain 33-letter set with none of the above |

**Decision tree.** љ њ ђ ћ џ → Serbia/Montenegro. Nine extras → Kazakhstan. Only ө ү →
Mongolia. і ї є ґ → Ukraine. ъ as a constant spoken vowel with no ы/э/ё → Bulgaria. None of
the above → Russia (or Belarus, which adds ў; unverified).

## Arabic family

| Variant | Extra letters | Where |
|---|---|---|
| **Arabic** | Base abjad, none of the below | Arab world |
| **Persian** | Arabic plus exactly 4: **پ چ ژ گ** | Iran, Afghanistan, Tajik-Persian areas |
| **Urdu** | Persian's four **plus** retroflex **ٹ ڈ ڑ** (small triangle marker), **ے**, **ں**, **ھ** | Pakistan, Urdu-speaking India |

## Commonly confused pairs

| Pair | Tell |
|---|---|
| Spanish / Portuguese | ã õ = Portuguese. ñ = Spanish |
| Romanian / Italian | ă â î ș ț = Romanian; Italian has only accented plain vowels |
| Czech / Slovak / Polish | ř = Czech only. ł ą ę ż = Polish. ô = Slovak, not Czech |
| Danish-Norwegian / Swedish | æ ø å vs å ä ö |
| Russian / Ukrainian / Bulgarian / Serbian | see the Cyrillic table |
| Arabic / Persian / Urdu | see the Arabic table |
| Dutch / Afrikaans | *unverified* |
| Indonesian / Malay | *unverified* |

**Number formats** *(medium confidence, general knowledge rather than per-article checked)*:
US/Canada 10 digits as `(NPA) NXX-XXXX` — the parenthesised 3-3-4 rhythm is unmistakable.
France 10 digits in **five pairs**, `0X XX XX XX XX`, also very recognisable. Spain 9
digits with **no trunk prefix** (landlines start 8/9, mobiles 6/7). Italy keeps its leading
0 even when dialled internationally, unusual in Europe. Poland 9 digits as `XX XXX XX XX`.
Brazil uses a parenthesised 2-digit DDD area code. Germany has famously variable length and
inconsistent grouping, which is itself a tell.

## Road-sign typefaces

| Typeface | Where | Look |
|---|---|---|
| **Transport** | UK, Ireland; adapted in Iceland, Portugal, Greece (non-motorway), Denmark, Hong Kong, India, Indonesia, Iran, Kuwait, Malaysia, Nepal, Oman, Qatar, UAE, Bangladesh, Malta, Spain | Rounded letterforms, distinctive curved tails on lowercase **a, t, l**; mixed case |
| **DIN 1451** | Germany and a number of others | Geometric sans on a coarse compass-and-ruler grid; condensed (Engschrift) and medium (Mittelschrift) |
| **Highway Gothic (FHWA)** | US states that have not switched | All-caps oriented, tighter spacing, smaller counters |
| **Clearview** | 20 to 30 US states, parts of Canada (BC, Ontario), Indonesia, Philippines, Israel, Panama, Brazil, Sri Lanka | Larger counters, higher x-height, designed for mixed case |
| **NEN 3225** | Netherlands | Humanist sans/serif hybrid, distinct from DIN's pure geometry |

*Swedish Tratex, Danish, Swiss SNV and Australian typefaces were not verified. Do not
invent their signatures.*
